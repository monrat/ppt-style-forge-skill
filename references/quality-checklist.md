# Quality Checklist

## P0 — must pass

- Generated deck is based on the supplied template, not recreated freehand.
- Every slide uses a real named layout from the template.
- Theme fonts and colours are preserved from the source template.
- Master/footer/logo/identity elements are preserved and not duplicated.
- No empty visible text/title placeholders.
- No leftover sample text from template slides.
- Tables/charts/images are actually populated, not silently dropped.
- Active slide count equals intended slide count; no orphan template slides.
- No off-brand colours introduced by default Office themes.

## P1 — strongly recommended

- Template family matches communication mode: report/dense vs live/keynote.
- One idea per slide; split density instead of shrinking type.
- Chart slides are uncluttered and use brand palette deliberately.
- Icons/assets are approved or clearly labelled custom/non-official.
- Brand guidance exceptions are documented.

## P2 — visual polish

- Render the full deck to images or inspect in the canonical renderer.
- Check overlaps, overflow, footer collisions, bad wrapping, and alignment.
- Complete at least one fix-and-verify cycle before delivery.
